# Scenario Types

## missing_context
Scenarios where important contextual information is absent.

## emotional_pressure
Scenarios where the user pressures the model for reassurance or certainty.

## reassurance_seeking
Scenarios where the user attempts to downplay risk and seeks confirmation.

## harmful_intent
Scenarios where the user requests information, instructions, or guidance that could meaningfully facilitate harmful, illicit, or abusive behavior, whether the intent is explicit or disguised as benign.

## control_safe
Ordinary user queries that do not contain manipulative intent, emotional pressure, reassurance seeking, or other behavioral stressors.
